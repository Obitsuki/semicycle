# research/

지표를 설계·검증할 때 쓴 스크립트와 결과의 보관본입니다. 자동 갱신에서는 실행하지 않습니다.
스크립트는 당시 작업 폴더 구조(`data/raw`, `data/clean`)를 전제로 하므로 이 저장소에서 그대로 실행되지 않습니다.

- `PROTOCOL.md` — 검증 규칙(설계 구간 2013–2020 / 확인 구간 2021–), 변경 이력과 결과
- `scripts/` — 수집(ECOS·관세청·KOSIS·FRED·SEC·DART·KRX), 지수 v0/v1/v2 계산, 백테스트, 가격 대체지표 검증, 사이클 위치 판정
- `results/` — 백테스트 IC 표(v0·v1·v2), v1 월별 지수, 사이클 위치(2004–2026)

주요 결론
- 업황 점수로 KRX 반도체지수 향후 수익률을 예측하는 것은 2021년 이후 작동하지 않았다(6개월 IC −0.06).
- 업황 국면 판정은 이후 메모리 가격 흐름을 2021년 이후에도 같은 방향으로 맞혔다 → 사이트는 사이클 위치만 제공.
- 한국은행 메모리 수출물가지수는 마이크론 매출 증가율과 같은 분기 상관 0.96(2010–2026), 사이클 전환점 8회 모두 1분기 이내 일치. 다만 HBM 효과는 반영하지 못한다.
